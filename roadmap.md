# Roadmap / Hoja de ruta

## English

### Next

- Validate the standalone Qt/QML path and card reader against larger packs.
- Add more curated recipes based on repeated OSCP lab usage.
- Add optional keyboard-only command palette.
- Re-run the live inventory after material Kali upgrades.
- Publish the prepared static PWA on GitHub Pages after repository review.

### Explicit non-goals

- Automatic execution of offensive commands.
- Kali, VPN, virtual-machine, terminal or remote-lab control.
- Storage of targets, credentials or engagement data.
- Access to personal writeups, private vaults or infrastructure-specific paths.
- Cloud synchronization, telemetry or user accounts.

## Español

### Próximo

- Validar el lector standalone Qt/QML de rutas y tarjetas con paquetes mayores.
- Añadir recetas revisadas según el uso repetido en laboratorios OSCP.
- Añadir una paleta de comandos opcional controlable solo por teclado.
- Regenerar el inventario vivo después de actualizaciones importantes de Kali.
- Publicar la PWA estática preparada en GitHub Pages tras revisar el repositorio.

### Fuera de alcance

- Ejecución automática de comandos ofensivos.
- Control de Kali, VPN, máquinas virtuales, terminales o laboratorios remotos.
- Almacenamiento de objetivos, credenciales o datos de auditorías.
- Acceso a writeups personales, bóvedas privadas o rutas específicas de una infraestructura.
- Sincronización cloud, telemetría o cuentas de usuario.
